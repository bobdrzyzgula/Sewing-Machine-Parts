# Sewing Machine Parts

A collection of small, 3D-printable replacement parts for sewing machines,
designed by Bob Drzyzgula. Each part has its own folder with an OpenSCAD source
file, a ready-to-print STL and a README covering hardware, printing and
installation. Every part is MIT licensed.

*This README was written by Claude (Anthropic) at Bob Drzyzgula's direction.*
